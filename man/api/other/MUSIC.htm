OpenFile()

DWORD OpenFile(LPCSTR  filepath);
DWORD OpenFile(LPCWSTR filepath);

功能：
打开音乐文件。成功打开后播放状态为 MUSIC_MODE_STOP。

参数：


    
参数含义

    
filepath带路径的文件名。




返回值：
操作成功返回 0，操作失败返回非 0。




IsOpen()

int IsOpen();

功能：
判断是否已经打开了音乐文件。

参数：
（无）

返回值：


    
值含义

    
1已打开音乐文件。

    
0未打开音乐文件。







GetPlayStatus()

DWORD GetPlayStatus();

功能：
获取当前播放状态。

参数：
（无）

返回值：
播放状态，为以下值之一：


    
常量含义

    
MUSIC_MODE_NOT_OPEN没有正确打开音乐文件。

    
MUSIC_MODE_NOT_READY设备未准备好（较少使用）。

    
MUSIC_MODE_PAUSE暂停中。

    
MUSIC_MODE_PLAY正在播放。

    
MUSIC_MODE_STOP成功打开后，或播放完毕后的状态。

    
MUSIC_MODE_OPEN打开中（较少使用）。

    
MUSIC_MODE_SEEK定位中（较少使用）。







Play()

DWORD Play(DWORD dwFrom = MUSIC_ERROR, DWORD dwTo = MUSIC_ERROR);

功能：
播放音乐。

- 无参数时，为继续播放（从暂停位置恢复）。

- 调用 Play(0) 为从头开始播放。

播放状态变为 MUSIC_MODE_PLAY。

参数：


    
参数含义

    
dwFrom音乐播放开始位置（毫秒）。

    
dwTo音乐播放结束位置（毫秒）。




返回值：
操作成功返回 0，操作失败返回非 0。




Pause()

DWORD Pause();

功能：
暂停播放。播放状态变为 MUSIC_MODE_PAUSE。

参数：
（无）

返回值：
操作成功返回 0，操作失败返回非 0。




Stop()

DWORD Stop();

功能：
停止播放。播放状态变为 MUSIC_MODE_STOP。

播放将停止，但播放进度保持不变（下次播放从停止位置继续）。

参数：
（无）

返回值：
操作成功返回 0，操作失败返回非 0。
